| \*\*🎨 Day 0: Nghiên cứu công cụ vẽ - Lựa chọn Krita\*\* | \*\*🎨 Day 0: Researching Drawing Tools - Choosing Krita\*\* |

| Hôm nay tập trung nghiên cứu và chốt phần mềm đồ họa chính để sản xuất Asset cho dự án game 2D. | Today's focus is on researching and finalizing the main graphics software for producing assets for a 2D game project. |

| \*\*🎯 Định hướng Phong cách Đồ họa (Art Style):\*\* | \*\*🎯 Art Style Orientation:\*\* |

| - \*\*Phong cách hướng tới:\*\* \*\*Hand-drawn 2D / Smooth Vector \& Digital Art\*\* (Đồ họa nét mượt, chi tiết và mượt mà, không dùng Pixel Art).<br>- \*\*Mục tiêu:\*\* Tạo cảm giác hình ảnh nghệ thuật, mịn màng và chuyển động tự nhiên cho nhân vật cũng như bối cảnh. | - \*\*Aimed Style:\*\* \*\*Hand-drawn 2D / Smooth Vector \& Digital Art\*\* (Smooth, detailed, and fluid graphics; no pixel art).<br>- \*\*Goal:\*\* To create an artistic, smooth visual feel and natural movement for characters and backgrounds. |

| \*\*⚔️ Đánh giá Krita cho dự án:\*\* | \*\*⚔️ Krita Evaluation for the Project:\*\* |

| \*\*1. Lý do chọn Krita làm công cụ chính:\*\*<br>- \*\*Miễn phí 100% \& Mã nguồn mở:\*\* Không lo vấn đề bản quyền hay chi phí phần mềm.<br>- \*\*Nét vẽ mượt mà (Smooth Brushes):\*\* Hệ thống cọ vẽ cực kỳ mạnh mẽ, hỗ trợ tính năng làm mịn nét (Brush Smoothing), giúp đi nét nhân vật không bị run tay.<br>- \*\*Đa năng:\*\* Vừa làm được Asset trong game (Characters, Environment, UI), vừa vẽ được Concept Art và Poster quảng bá cho game sau này.<br>- \*\*Hỗ trợ Animation 2D:\*\* Có sẵn Timeline làm hoạt ảnh Frame-by-Frame trực quan. | \*\*1. Reasons for choosing Krita as the main tool:\*\*<br>- \*\*100% Free \& Open Source:\*\* No worries about copyright or software costs.<br>- \*\*Smooth Brushes:\*\* An extremely powerful brush system, supporting Brush Smoothing, ensuring smooth character lines without shaky hands.<br>- \*\*Versatile:\*\* Can be used to create in-game assets (Characters, Environment, UI) and also for creating concept art and promotional posters for the game later.<br>- \*\*2D Animation Support:\*\* Includes a built-in timeline for intuitive frame-by-frame animation. |

| \*\*2. Các điểm cần lưu ý khi xuất Asset cho Unity:\*\*<br>- Cần chú ý quản lý kích thước Canvas và độ phân giải (DPI/Resolution) chuẩn ngay từ đầu.<br>- Cần tổ chức Layer gọn gàng để dễ dàng Export ra các file `.png` tách nền cho Unity. | \*\*2. Points to Note When Exporting Assets to Unity:\*\*<br>- Pay attention to managing canvas size and resolution (DPI/Resolution) correctly from the start.<br>- Organize layers neatly for easy export of `.png` files with transparent backgrounds for Unity. |

| \*\*🚀 Quyết định:\*\*<br>- Chốt sử dụng \*\*Krita\*\* làm phần mềm đồ họa chính cho toàn bộ dự án. | \*\*🚀 Decision:\*\*<br>- Final decision to use \*\*Krita\*\* as the primary graphics software for the entire project. |
